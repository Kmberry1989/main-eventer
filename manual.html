Main Eventer is Fired Arts Studio’s event-uniformity tool. One event record produces matching copy for every channel, and any text already written can be checked against that record, field by field.

The event record

The form is the event record. Every output on the page reads from it. All fields are optional — nothing is required to save or generate. When a field is left blank, it is omitted from the generated outputs: no empty labels, no stray punctuation, no blank lines where the detail would have gone.

  • Event name — the event’s title. Flagged when blank.
  • Date — the event date. Flagged when blank.
  • Start time — when the event begins. Flagged when blank.
  • End time — when the event ends. Flagged when blank.
  • Price — what it costs (for example $25, $45, Free). Flagged when blank.
  • Ages — who it is for (for example 6-12, 18+). Flagged when blank.
  • Host — the person hosting the event (host or hostess, just a name).
  • Location — where it happens (for example 111 W Sycamore St, Kokomo).
  • Description — a short description of the event.
  • Link — the registration or event page link.

Canonical line. Below the form, the canonical line is the record reduced to one line: name, date, times, host, price, ages, location — joined with ·. It is the single line every channel’s copy is built from.

Caution flags. When an important field is left blank, a warning triangle (⚠) appears next to its label and the field’s border turns amber: name, date, start time, end time, price, ages. Host, location, description, and link do not get a flag. The flag is a warning only — it never blocks saving or generating.

Outputs

Each channel’s text is generated from the record and shown in its own card, with a Copy button:

  • Google Calendar — event description for the calendar, plus an Open in Google Calendar link and a Download .ics button.
  • Website listing — title, date and times, price, ages, host, location, description, registration link.
  • Facebook post — title with short date and time, description, details, registration link.
  • Instagram caption — title with short date and time, description, details, “Link in bio to register”, and the hashtags #FiredArtsStudio #KokomoIN #PaintYourOwnPottery.
  • Threads post — title, short date and time, price, ages, host, link, joined with ·.
  • TikTok caption — title, short date and time, location, host, registration link, and the hashtags #FiredArtsStudio #KokomoIN #PYOP.
  • Pinterest description — title with long date, description, details, link.
  • Flyer text — title in capitals, long date, time range, price, ages, host, location, link. This is the text to put on a graphic.

Download CSV downloads one CSV row of the record (columns: title, date, weekday, start time, end time, price, ages, host, location, description, link) for Canva bulk create.

The Open in Google Calendar link and the Download .ics button need a name, date, and start time; otherwise they stay inactive.

Google push

The Google card has two buttons that push the record straight to Google:

  • Add to Google Calendar — creates the event on the signed-in Google account’s primary calendar (timezone America/Indiana/Indianapolis). Needs a name, date, and start time.
  • Add row to Google Sheet — appends the record as a row to a configured sheet (same columns as the CSV download).

These need a Google OAuth client. Until it is set, the buttons say what is still needed. One-time setup:

  1. In Google Cloud Console, open the fired-arts-dashboard project.
  2. Enable the Google Calendar API and the Google Sheets API (APIs & Services → Library).
  3. Create an OAuth 2.0 Client ID (APIs & Services → Credentials → Create Credentials → OAuth client ID), type Web application.
  4. Add https://main-eventer.netlify.app to Authorized JavaScript origins. No redirect URI is needed (the app uses a token client).
  5. Copy the client ID into GOOGLE_OAUTH_CLIENT_ID in index.html.
  6. For Sheets: create a sheet, copy its ID from its URL, and put it in GOOGLE_SHEET_ID in index.html. The first row should be: title, date, weekday, start_time, end_time, price, ages, host, location, description, link.

Check a post

Paste the text of anything already written or already live — a website listing, a caption, the words on a flyer — pick where the text lives, and run Check it. Each field is compared against the record and flagged Match, Conflict, or Not stated:

  • Date — month and day.
  • Day of week — the weekday the record’s date falls on.
  • Times — start and end times. A PM time where the record says AM (or the reverse) is a conflict.
  • Price — dollar amounts, or Free.
  • Ages — the age range.
  • Host — a name after Host:, Host, or Hosted by.

A field the pasted text never states is flagged Not stated, not passed: a post that omits the time can’t conflict with it, but it can’t confirm it either. A field the record leaves blank is skipped the same way — it shows as Not stated, never as a conflict.

The verdict line reads Uniform. when every stated field matches, N conflicts with the record. when anything disagrees, or No conflicts — M fields match, N not stated. when nothing conflicts but something was left out.

Saved events

Sign in with Google (top of the page) signs in with a Google account. Only the studio accounts can save: kylematthewberry@gmail.com and rochelleberry731@gmail.com. The same allowlist is enforced by the Firestore rules.

  • Save event saves the current record to Firestore (collection mainEvent_events, project fired-arts-dashboard). Saving a record that is already loaded updates it; saving a new one creates it.
  • Saved events lists the saved records. Tap one to load it into the form. Delete removes it.
  • New event clears the form.

Tutorial and Help

The first time the tool is opened, a short tutorial overlay appears: enter the event once, copy the matching posts and calendar event, check live posts against the record. It has a Close button and does not reappear after being dismissed.

A small Help link sits in fine print at the bottom of the page. It opens this manual.

Deploy

  • Site: Netlify, from this repo. Publish directory is the repo root.
  • The Netlify badge (“Powered by Netlify”) is off: it is opt-in in Netlify site settings and is not enabled for this site. If it ever appears, turn it off in Site settings → General → Site details.
  • Firebase project: fired-arts-dashboard (shared with Arts Fired). The Netlify domain (main-eventer.netlify.app) is in the Firebase Auth authorized-domains list.
